DIALOGUE 2026-11-01

Using a parcel locker

小区智能快递柜取件（取件码过期）

傍晚回到小区，快递柜屏幕提示取件码过期；门口碰到邻居，请对方帮忙看一下 App 和柜机操作。

对话 · Dialogue

**A

** Excuse me, do you know how this locker works? My pickup code keeps saying it’s expired.

**B

** Sure. Have you tried requesting a new code in the app?

**A

** I did, but the door still won’t open.

**B

** Sometimes you need to tap “Open again” within two minutes. Want me to show you?

**A

** That would be great. Thanks so much.

**B

** No problem. Just tap here… There you go.

**A

** Perfect! I was worried I’d have to pick it up from the collection point tomorrow.

值得学的表达

  1. That would be great — 礼貌地接受别人的帮助/提议。
  2. No problem — 非正式口语：答应帮忙，或回应别人的感谢。
  3. pick (something) up — 去某处取/领（包裹、预订的东西等）。
  4. keep + -ing — 反复或持续发生。
  5. There you go — 把东西递给对方、或帮对方弄好时的口语。
